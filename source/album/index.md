<!--
  ===========================================================================
  相册页 —— 这里写满了注释作为「怎么往里放照片」的说明。
  注释不会出现在页面上（构建脚本 scripts/strip-comments.js 会剥掉），
  所以可以放心留在这里当参考；看完想删也随意。
  ===========================================================================

  本站用的是 Butterfly 内置的相册标签，**不需要装额外插件**：
      主题文件 themes/butterfly/scripts/tag/gallery.js
      可用的两个标签：{% galleryGroup %} 和 {% gallery %}

  ── 一、相册主页（就是这个页面）------------------------------------------------
  用 {% galleryGroup 名称 描述 链接 封面图 %} 列出每一本相册的封面卡片。
  下面「使用示例」那段就是现成写法，把 ### 那几行换成你的内容即可。

  ── 二、每本相册的内容页 --------------------------------------------------------
  在同样的位置再建一个页面，比如 source/album/travel/index.md，
  里面的 front-matter 照抄本文件（title 改成相册名），正文用：

      {% gallery %}
      ![](/img/album/travel/01.jpg)
      ![](/img/album/travel/02.jpg)
      {% endgallery %}

  然后主页那张卡片的链接就指向 /album/travel/。

  ── 三、图片放哪 ----------------------------------------------------------------
  放 source/img/album/ 下面（按相册分文件夹），引用写成 /img/album/xxx/01.jpg。
  ⚠️ 建议先把图压到 200~400 KB 以内再放进仓库，否则首页列表会变慢。
     本站图片目前都是 WebP，能用 WebP 更好。

  ── 四、为什么现在页面上没有照片 -------------------------------------------------
  因为**还没有提供任何图片**。按你之前定的规矩，我不擅自加新图片，
  所以这里先只放结构和一个空状态提示，等你把图给我或放进 source/img/album/，
  我再把卡片补上。

  使用示例（把 ### 开头的行取消注释并改成你的内容即可）：

  ### {% galleryGroup '旅行' '去过的地方' '/album/travel/' '/img/album/travel/cover.jpg' %}
  ### {% galleryGroup '日常' '随手拍' '/album/daily/' '/img/album/daily/cover.jpg' %}
  ===========================================================================
-->
